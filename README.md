# Dotfiles Summary

This repository contains three folders. Within these three folders, there are scripts to add new functionaltiy to your `bash` environment. To make use of these scripts, run this command to clone the repository.

```
git clone https://github.com/LilacLeopard/dotfiles.git
```
Then, you can move to each individual folder to run the scripts inside them.

## `homefiles`

This folder includes scripts to add bash aliases and a new command to your `.bashrc` file. You can find the instructions for running these scripts [here](https://github.com/LilacLeopard/dotfiles/blob/main/homefiles/README.md).

## `vim-config`

This folder contains a script to improve your `vim` editor. It will download packages that will augment your `vim` environment. You can find the instructions to run this script [here](https://github.com/LilacLeopard/dotfiles/blob/main/vim-config/README.md).

## `sys-installs`

This folder contains a script that will automatically download a new package to your system. You can find the instructions for running this script [here](https://github.com/LilacLeopard/dotfiles/blob/main/sys-installs/README.md).
